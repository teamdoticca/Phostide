# Phostide site

Marketing + documentation site for [phostide.doticca.com](https://phostide.doticca.com).

## Develop

```powershell
cd site
npm install
npm run dev
```

## Deploy

Pushes to `main` deploy via the Vercel project `phostide` (Doticca team).
Production aliases: `phostide.doticca.com`, `phostide.vercel.app`.
