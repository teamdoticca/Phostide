# Security Policy

## Supported versions

Security fixes target the latest published release on [GitHub Releases](https://github.com/teamdoticca/Phostide/releases). Older tags are not maintained.

## Reporting a vulnerability

Phostide injects a helper into Explorer and paints the real taskbar background. Treat injection, privilege, and restore-on-exit issues seriously.

**Please do not open a public Issue for security reports.**

1. Prefer [GitHub Security Advisories](https://github.com/teamdoticca/Phostide/security/advisories/new) for `teamdoticca/Phostide`.
2. If that is unavailable, email **security@doticca.com** with a clear description, impact, and steps to reproduce.

We will acknowledge receipt when we can and coordinate a fix before any public disclosure.
